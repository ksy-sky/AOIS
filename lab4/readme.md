##  О проекте

Реализация хеш-таблицы на Python с разрешением коллизий методом **квадратичного пробирования**.

Хеш-таблица позволяет:
-  Быстро искать данные по ключу
-  Добавлять новые записи
-  Обновлять существующие
-  Удалять записи (мягкое удаление)

---

## Хеш-функция

Используется функция из методички:

1. Русский алфавит: **А=0, Б=1, В=2, ..., Я=32**
2. Берутся **первые две буквы** ключевого слова
3. `V = код₁ × 33 + код₂`
4. `h = V mod H`, где `H = 21` (размер таблицы)

### Пример

```
"Амеба" → А=0, м=13 → V = 0×33+13 = 13 → h = 13 mod 21 = 13
"Вирус" → В=2, и=9 → V = 2×33+9 = 75 → h = 75 mod 21 = 12
```

---

## Разрешение коллизий

Если два ключа получают одинаковый хеш (`h`), возникает **коллизия**.

**Решение:** квадратичное пробирование

```
index = (h + i²) mod H, где i = 1, 2, 3, ...
```

### Пример коллизии

| Ключ | h | Попытки | Итоговый индекс |
|------|---|---------|-----------------|
| Бактерия | 12 | — | 12 |
| Вирус | 12 | 12 → 13 → **16** | 16 |
| Цитоплазма | 12 | 12 → 13 → 16 → 0 → **7** | 7 |

## Структура ячейки (строки таблицы)

В соответствии с методичкой (Рисунок 1):

| Поле | Название | Значение |
|------|----------|----------|
| `ID` | Ключевое слово | Биологический термин |
| `C` | Collision | 1 — запись вставлена из-за коллизии |
| `U` | Used | 1 — ячейка занята |
| `T` | Terminal | Всегда 1 (для открытой адресации) |
| `L` | Link | Не используется (0) |
| `D` | Deleted | 1 — запись удалена (мягкое удаление) |
| `Po` | Pointer | Не используется (-1) |
| `Pi` | Data | Описание термина |

## Как это работает (кратко)

| Операция | Алгоритм |
|----------|----------|
| **Вставка** | Вычисляем `h`. Если ячейка свободна — вставляем. Если занята — применяем квадратичное пробирование. |
| **Поиск** | Вычисляем `h`. Идём по цепочке пробирования, пока не найдём ключ или не встретим никогда не занятую ячейку. |
| **Удаление** | Находим запись. Устанавливаем `D=1` (мягкое удаление), `U` оставляем `1`. Это не разрывает цепочку поиска. |
| **Обновление** | Находим запись. Меняем `Pi` на новое описание. |
